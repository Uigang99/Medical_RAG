KEV 메인·서브 정보 역할 파일럿 (2026-10-25~26, Asia/Seoul)

판단
메인 라벨 중심의 비배타적 보조 메타데이터로는 점진 확장을 시도할 만하다.
메인 한 개만으로 명제를 제외하거나, 서브 라벨의 부재를 정보 부재로 판단하는
용도로는 승인하지 않는다. 원문은 보존해야 한다. 전체 데이터 라벨링은 실행하지 않았다.
이 판단은 절대적인 정답 라벨의 정확도가 아니라, 새 표본의 정성 검토와 임시
우선순위 기준의 일치도를 근거로 한 운영상 판단이다. QA 성능 개선은 측정하지 않았다.

목적과 동작
기존의 여섯 개 동등한 YES/NO/UNCERTAIN 판정에서, 핵심 역할 선택을 분리했다.
1. KEV에 명제 하나만 입력하고 중심 주장에 가장 적합한 메인 역할 하나를 선택한다.
   DEFINE(정의·분류), DESCRIBE(특성·관찰), EXPLAIN(원인·작용),
   ASSESS(식별·평가), METHOD(수행·방법), NORM(권고·규범).
   적합한 역할이 없으면 OTHER, 뜻이 불명확하면 UNCERTAIN을 허용한다.
2. 명제와 선택한 메인 라벨을 입력하고 나머지 역할의 추가 정보가 실제로 있는지
   YES/NO/UNCERTAIN으로 판정한다. 서브 라벨은 없어도 된다.
3. 원문, 메인, 서브 판정 전체와 확률을 저장한다. 생성형 rationale은 요구하지 않는다.
학습은 하지 않았다. KEV 가중치와 corpus는 고정하고 프롬프트만 수정했다.
분류 대상은 문장의 정보 역할이지 의학적 진위, 질문 관련성, 명제쌍의 논리 관계가 아니다.

입력과 일반화 통제
개발 92개: 이전 공식 train 명제 파일럿의 development만 사용했다.
새 확인 128개: 공식 MedMCQA/MedQA train 검색 근거에서 source별 32개씩 선정했다.
Textbooks, CPG, PubMed, PMC 각각 서로 다른 source document 32개이며, 과거
개발/확인 표본의 모든 문서와 동일 정규화 명제를 제외했다. 원문 문서는 검색 chunk
단위이며, 같은 책·저널 전체를 분리한 것은 아니다. 질문, 선택지, QA 정답, 기존
라벨, 원문 문서 문맥은 KEV 입력에 넣지 않았다. 128개는 corpus 비율에 따른 무작위
표본이 아니라 source 균형 표본이다. 원문 자체의 정확성은 이 파일럿에서 검증하지 않았다.

새 메인 라벨 판정 전에 assistant가 단일 선호 메인, 타당한 대안 메인, 허용 서브,
핵심 부가 역할을 기록했다. 과거 개발 표본의 다중라벨 출력은 이미 알려져 있었으나
새 메인 라벨 출력과 새 확인 표본의 KEV 출력은 보지 않은 상태였다.
단일 라벨만 타당하지 않은 문장은 사전에 대안을 허용했다. 선호 일치와 대안 포함
일치를 별도 보고하며, 출력 이후 임시 기준을 변경하지 않았다. 독립 인간 gold는 아니다.
개별 질환명, 명제 ID, 수치별 예외나 정답을 프롬프트에 주입하지 않았다.

버전별 검토 (모두 개발 92개, 매번 전체 출력을 직접 확인)
       선호 메인 일치     타당 메인 일치       허용 서브/부여 서브
P1     62/92 (67.39%)    66/92 (71.74%)      15/21 (71.43%)
P2     71/92 (77.17%)    78/92 (84.78%)      12/18 (66.67%)
P3     74/92 (80.43%)    82/92 (89.13%)      12/18 (66.67%)
P4     74/92 (80.43%)    82/92 (89.13%)      19/44 (43.18%)
P3-P1: 선호 메인 +13.04%p, 타당 메인 +17.39%p.
P2: 모든 사실을 DESCRIBE로 보는 경향을 막고 중심 주장 자체의 기능을 구분했다.
P3: 권고의 이유를 메인 인과로 오인하는 문제, 완곡한 인과를 관찰로 낮추는 문제를 보완했다.
P4: 메인은 P3와 완전히 동일. 서브 설명을 구체화했지만 불필요한 역할이 증가했다.
P4는 채택하지 않았다. P3를 확인 표본 생성 전에 고정했다.

참고: 기존 V2의 YES 확률이 가장 큰 라벨을 임의의 메인으로 삼으면 같은 개발
92개에서 선호 71개, 타당 77개다. 기존 모델은 중요도를 판정한 것이 아니므로
이를 본래의 메인 라벨 baseline이라고 해석하면 안 된다. 기존의 모든 YES 중
핵심이 포함된 경우는 90/92, P3 메인+서브는 84/92였다. 이번 변경은 불필요한
부가 라벨을 줄이고 핵심 순위를 명확히 하는 대신 일부 후보를 잃는 trade-off도 있다.

새 확인 128개 결과
고정 초안 P1을 비교군으로 추가한다고 결과 생성 전에 선언했다. 두 고정 버전을
한 번씩 실행했으며, 확인 결과로 후보를 다시 고르거나 프롬프트를 수정하지 않았다.

                                  P1                 P3                 절대 변화
선호 메인 일치                    94/128=73.44%      101/128=78.91%     +5.47%p
사전 허용 대안을 포함한 메인      109/128=85.16%     115/128=89.84%     +4.69%p
메인 또는 서브에 핵심 보존        112/128=87.50%     121/128=94.53%     +7.03%p
허용 서브/실제 부여 서브           17/19=89.47%       20/23=86.96%       -2.52%p

서브 precision의 분모는 부여한 라벨 수이며, 두 버전의 분모가 다르다.
사전에 명확한 부가 정보로 기록한 12개 기능의 메인+서브 보존은 두 버전 모두 8/12.
서브 누락 문제까지 해결됐다고 볼 수 없다.

타당 메인 기준: 개선 12개, 악화 6개, 유지 110개. 대응 exact McNemar p=0.238로,
이 표본에서 개선이 통계적으로 확정됐다고 주장하지 않는다. P3 타당 메인 비율의
Wilson 95% 구간은 약 83.40~93.97%다. 서로 다른 source document 표본이지만
같은 분야/책의 상관성이 남을 수 있다. 결측/파싱 실패는 없다.

Source별 타당 메인 (각각 N=32):
Textbooks 24→28 (+4; 75.00%→87.50%, +12.50%p)
CPG       30→30 (0; 93.75%→93.75%)
PubMed    28→27 (-1; 87.50%→84.38%, -3.13%p)
PMC       27→30 (+3; 84.38%→93.75%, +9.38%p)
모든 source에서 균일한 개선은 아니다. 권고 라벨의 선호 양성은 6개로 적고,
의료윤리의 다양한 문제 유형을 별도 검증하지 않았다.

정성 검토
좋은 사례:
- H020: 직접적인 작용을 단순 관찰 대신 메인 EXPLAIN으로 분류.
- H011: 검사의 한계를 ASSESS, 그 원인을 서브 EXPLAIN으로 분리.
- H022: 행동 권고를 NORM, 치료 수단을 서브 METHOD로 보존.
- H097: 정의를 DEFINE, 함께 제시된 유병 빈도를 서브 DESCRIBE로 보존.
- H004/H012/H077/H104: 환자 소견/빈도/연구 표본은 DESCRIBE로 유지.

남은 주요 문제:
- H006/H008/H094: 치료 효과·치료 수단이 DESCRIBE에 머무른다.
- H066/H108: 표준 치료 또는 보관 지침을 DESCRIBE로 선택. NORM은 서브로 남는다.
- H018/H052/H072: 정의/평가/기전이 메인 대신 서브로 내려간다.
- H088: 검사 수단을 METHOD로 보고 ASSESS를 서브로 둔다. 무관한 판단이라기보다
  기능 우선순위 문제지만, 특정 expert에 메인만으로 보내면 영향이 있다.

임시 기준과 다르더라도 타당한 판단도 있다. H010의 계산식을 DEFINE로 본 것,
H042의 비교 논의를 DESCRIBE로 본 것은 이해 가능한 해석이다. H117의 구체적
환자 투약 기록은 관찰이면서 절차 정보도 담는다. 이를 새로 정답 처리해 수치를
올리지 않았으며, 해석 차이는 정성 기록에 따로 남겼다.

서브는 과하게 생성하기보다는 적게 생성한다. 23개 중 20개가 사전 허용 범위에
들었지만, 이 적은 수로 전체 corpus의 서브 precision을 보장할 수 없다. 치료 가능성을
곧 권고로 읽거나, 절차의 수학적 규칙을 인과 설명으로 읽는 경계 오류가 남는다.

권장 사용 범위
P3를 고정한 채 메인 우선의 역할 메타데이터로 점진 확장할 수 있다고 판단한다.
다음 chunk에서도 source·예측 역할별로 표본을 확인하되, 확인 샘플에 맞춰 규칙을
계속 덧붙이지 않는다. 원문을 유지하고 서브는 보조 후보로 둔다. 메인/서브 라벨을
진위, 함의, 보완 관계가 검증됐다는 의미로 쓰지 않는다. 메인만으로 근거를 버리는
배타적 분류나 자동 임상 판단에는 이 검증만으로 충분하지 않다.
전체 자동 확장 또는 QA 개선이 검증되었다고 표현하지 않는다.

파일과 실행 검증
선택 프롬프트: docs/kev_primary_roles_p3.json
실행 코드: scripts/pilot_rag2_kev_primary_roles.py
로컬 결과: results/rag2_kev_primary_roles_pilot_v1/
  sampling_manifest.json, cohort.json, reference_before_primary_kev.json
  prompts/p1.json~p4.json, selection.json, baseline_frozen.json, comparison.json
  버전/분할별 manifest, raw request/cache, predictions, summary, qualitative_review
원본 명제와 모든 버전 출력은 보존했고, 모델/결과 데이터는 Git에 넣지 않았다.
GPU1의 H200, KEV-9B/Qwen3.5-9B-Base bfloat16, decision batch 48 사용.
6회 실행에서 총 3,758개 decision이 모두 완료됐고 OOM·batch fallback이 없었다.
실측 모델 로드 포함 합계 약 157초, 준비/직접 정성 검토 시간은 별도다.
이 시간으로 전체 corpus의 고정 ETA를 보장하지 않는다.
4개 개발 버전 한도에서 종료했으며, 새 확인 표본에 대한 추가 튜닝은 하지 않았다.
